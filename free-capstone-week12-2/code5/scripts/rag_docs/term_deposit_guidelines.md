# 적금 해지 및 만기 처리 가이드

## 1. 고객 확인 절차
- 고객명, 주민등록 앞 6자리, 계좌번호 2가지 이상으로 본인 확인.
- 비대면 요청 시 등록된 연락처로 1차 콜백.
- 특이 거래 이력(최근 30일) 조회 후 이상 징후 기록.

## 2. 상담 흐름
1. **요청 파악**: 중도해지 / 만기해지 여부 확인.
2. **수수료 설명**  
   - 중도해지: 약정이율 대신 중도해지 이율 적용.  
   - 만기일 경과 1개월 이내: 만기이자 그대로 지급.  
3. **필수 멘트**  
   - “중도해지 시 예상 수령액은 세후 약 ○○원입니다.”  
   - “세무 신고를 위해 이자내역 안내장을 전달드리겠습니다.”
4. **내부 체크리스트**  
   - 전자금융거래 정지 계좌인지 확인  
   - 대출 담보로 설정된 적금인지 여부 확인  
   - 해지 후 잔액 이체 목적지 기록

## 3. 증빙 및 시스템 입력
- 전자서식 `FD-CA-12` 사용.
- 고객 확인 서명 스캔 후 5년 보관.
- 이상 거래 의심 시 AML 팀 Slack 채널로 보고.

## 4. FAQ
- **만기 자동연장 해지 요청**: 당일 처리, 연장해지 수수료 없음.
- **제3자 대리 해지**: 위임장, 신분증 사본 2종 필요.
