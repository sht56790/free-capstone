# 대출 심사 단계별 체크리스트

## 1. 접수 단계
- 신청서 `LN-FORM-01` 업로드 여부.
- 신분증/소득증빙/거주증명 3종 확보.
- 상담 메모에 용도/상환계획 요약 필수.

## 2. 신용 분석
- 개인 CB 등급, 연체 이력, 보증/담보 내역 확인.
- 내부 스코어카드 `SC-2024` 적용 → 점수 680 미만 시 자동 보류.
- 소득 대비 부채비율(DTI) 산정: 총부채 / 연소득 × 100.

## 3. 심사 위원 검토
- **필수 확인 항목**
  - 직전 6개월 급여 입금 패턴
  - 타 금융기관 대출 만기 스케줄
  - 담보 감정가 재산출 여부
- **멘트 템플릿**
  - “추가 서류: 재직증명서(최근 1개월), 임차계약서 사본을 업로드 부탁드립니다.”

## 4. 승인/보류/거절 판단
- 승인: 조건부 이자율/한도/만기 입력 후 전자서명 안내.
- 보류: 보완 목록과 기한(영업일 기준 3일) 명시.
- 거절: 사유 코드와 고객 통보 스크립트를 상담원에게 전달.

## 5. 내부 통제
- AML/제재 리스트 자동 조회 결과 캡처 저장.
- 대출 실행 전 고객 정보 최신화(주소, 연락처, 직장) 재확인.
- 이상 징후는 `risk-alert@company.local`로 즉시 보고.
