# 정책표 v1 - 금융 상담 챗봇

## PII 분류

| 정보 유형 | 형식 | 예시 |
|---------|------|------|
| 계좌번호 | 12~14자리 숫자 | 123-456-789012, 12345678901234 |
| 고객번호 | 6~12자리 숫자 | 123456789 |
| 고객명 | 한글 2~4자리 | 홍길동, 김철수 |
| 생년월일 | YYYY-MM-DD, YYMMDD | 1990-01-01, 900101 |
| 전화번호 | 010-1234-5678 형식 | 010-1234-5678 |
| 주소 | 지역명 + 상세주소 | 서울시 강남구, 12345-67890 |

## 정책 매트릭스

| 민감정보 유형 | 행동 | 처리 방식 | 비고 |
|------------|------|----------|------|
| 일반 상식 질문 | Allow | ✓ | 정상 처리 |
| 공개 약관·수수료표 | Allow | ✓ | 정상 처리 |
| 계좌번호 | Block | ✗ | 고객정보 정책 - 즉시 차단 |
| 고객번호 | Block | ✗ | 고객정보 정책 - 즉시 차단 |
| 고객명 | Mask | "홍○○" | 부분 마스킹 처리 |
| 생년월일 | Mask | "1990년생" | 연도 단위 일반화/마스킹 |
| 전화번호 | Block | ✗ | 고객정보 정책 - 즉시 차단 |
| 주소 | Block | ✗ | 고객정보 정책 - 즉시 차단 |
| 수수료·금리 확정 표현 | Block | ✗ | "계산 불가, 영업점 문의" |

## 금지/허용 표현

### 금지 표현

| 금지 표현 | 대신 사용 |
|---------|----------|
| "수수료는 5,000원입니다" | "수수료는 약 3,000~8,000원 범위입니다. 정확한 금액은 영업점 문의 바랍니다." |
| "금리는 3.5%입니다" | "금리는 상품·기간에 따라 다르며, 정확한 금리는 영업점 문의 바랍니다." |
| "계좌 이체 가능합니다" | "계좌 이체는 직접 신청하거나 상담원 연결이 필요합니다." |

### 필수 면책 문구

⚠️ **참고용, 실제 상품 가입·거래는 영업점 방문 또는 상담원 연결이 필요합니다.**
