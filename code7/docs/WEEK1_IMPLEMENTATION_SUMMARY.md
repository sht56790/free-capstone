# 1주차 구현 내용 요약

## 📋 정책표 v1 작성 내용

### 1. `patterns.json` - 탐지 규칙 정의

**구조**: JSON 배열 형태로 10개의 민감정보 탐지 규칙 정의

**규칙 목록**:
1. **계좌번호** (Block)
   - 정규식: `\d{4}[-\\s]?\d{4}[-\\s]?\d{4,6}|\d{12,14}`
   - 설명: 12~14자리 계좌번호 패턴 (하이픈 포함/미포함)
   - 행동: 즉시 차단

2. **고객번호** (Block)
   - 정규식: `고객번호[:\\s]?\d{6,12}|\d{6,12}(?=\\s*고객)`
   - 설명: 6~12자리 숫자 패턴
   - 행동: 즉시 차단

3. **고객명** (Mask)
   - 정규식: `[가-힣]{2,4}(?=\\s*(님|고객|분|씨))|[가-힣]{2,4}(?=\\s*계좌)|성명[:\\s]*[가-힣]{2,4}`
   - 설명: 한글 이름 2~4자리 (맥락 포함)
   - 행동: 마스킹 처리 (예: "홍길동" → "홍○○")

4. **생년월일** (Block)
   - 정규식: `\d{4}[-.\\s]?\d{2}[-.\\s]?\d{2}|\d{6}(?=\\s*생년)|생년월일[:\\s]*\d{4}[-.\\s]?\d{2}[-.\\s]?\d{2}`
   - 설명: YYYY-MM-DD, YYMMDD 형식
   - 행동: 즉시 차단

5. **전화번호** (Block)
   - 정규식: `010[-\\s]?\d{4}[-\\s]?\d{4}|0\d{1,2}[-\\s]?\d{3,4}[-\\s]?\d{4}`
   - 설명: 010-1234-5678 형식
   - 행동: 즉시 차단

6. **주소** (Block)
   - 정규식: `([서울|부산|대구|인천|광주|대전|울산|세종|경기|강원|충북|충남|전북|전남|경북|경남|제주]\\s*[시도군구]|\\d{5}[-\\s]?\\d{6})`
   - 설명: 지역명 + 우편번호
   - 행동: 즉시 차단

7. **금리 확정 표현** (Block)
   - 정규식: `금리는\\s*\\d+[.\\d]*%입니다|금리\\s*\\d+[.\\d]*%|이자율\\s*\\d+[.\\d]*%`
   - 설명: "금리는 3.5%입니다" 같은 확정 표현
   - 행동: 즉시 차단

8. **수수료 확정 표현** (Block)
   - 정규식: `수수료는\\s*\\d+[,\\d]*원입니다|수수료\\s*\\d+[,\\d]*원|보험료는\\s*\\d+[,\\d]*원입니다`
   - 설명: "수수료는 5,000원입니다" 같은 확정 표현
   - 행동: 즉시 차단

9. **계좌 이체 요청** (Block)
   - 정규식: `계좌\\s*이체|송금\\s*요청|이체\\s*가능`
   - 설명: 계좌 이체 관련 요청
   - 행동: 즉시 차단

10. **대출 신청** (Block)
    - 정규식: `대출\\s*신청|대출\\s*가입|대출\\s*가능`
    - 설명: 대출 신청 관련 요청
    - 행동: 즉시 차단

## 🧪 벤치셋 30케이스 작성 내용

### 구조: `benchmark_30_cases.json`

**카테고리별 분류** (각 카테고리당 6케이스):
1. **계좌 이체** (6케이스)
   - 계좌번호 + 이체 요청 (Block)
   - 계좌 이체 키워드 (Block)
   - 송금 요청 (Block)
   - 계좌 이체 수수료 문의 (Block)
   - 이체 가능 문의 (Block)
   - 계좌 이체 서비스 문의 (Block)

2. **수수료** (6케이스)
   - 수수료 확정 표현 (Block)
   - 수수료 일반 문의 (Allow)
   - 보험료 확정 표현 (Block)
   - 수수료 범위 표현 (Allow)
   - 수수료 불확정 표현 (Allow)
   - 수수료 확정 + 계좌 이체 (Block)

3. **상품 가입** (6케이스)
   - 보험 가입 문의 (Allow)
   - 고객명 + 보험 가입 (Mask)
   - 대출 신청 (Block)
   - 대출 가입 절차 (Block)
   - 보험 가입 방법 문의 (Allow)
   - 고객명 + 실제 거래 요청 (Block)

4. **금리** (6케이스)
   - 금리 확정 표현 (Block)
   - 금리 일반 문의 (Allow)
   - 이자율 확정 표현 (Block)
   - 금리 불확정 표현 (Allow)
   - 금리 범위 표현 (Allow)
   - 금리 정보 문의 (Allow)

5. **약관 해석** (6케이스)
   - 약관 보장 범위 문의 (Allow)
   - 고객번호 + 약관 확인 (Block)
   - 생년월일 + 상품 문의 (Block)
   - 전화번호 + 연락 요청 (Block)
   - 주소 + 배송 요청 (Block)
   - 약관 면책 사항 문의 (Allow)

**총 통계**:
- 총 30케이스
- Block: 18케이스 (60%)
- Mask: 1케이스 (3%)
- Allow: 11케이스 (37%)

**각 케이스 구조**:
```json
{
  "id": 1,
  "input": "실제 입력 텍스트",
  "expected_action": "block|mask|allow",
  "expected_reason": "차단/마스킹/허용 이유",
  "test_type": "block|mask|allow"
}
```
